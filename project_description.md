## PROJECTS

**Smart Restaurant - Smart Restaurant Management System** *(12/2025 - Now)*

**Role**: Full Stack Developer (Team size: 3)

**Tech stack**: ReactJS, Express, PostgreSQL, Redis, Socket.io, AWS (EC2, S3), GitHub Actions.

*   **Frontend Architecture**: Designed and developed interactive, responsive web applications using React.js and Tailwind CSS. Implemented complex UI flows including QR-based dynamic table joining, interactive digital menus, and live order status tracking.
*   **Backend & Database**: Engineered a scalable RESTful API using Node.js and Express, connected to a robust PostgreSQL relational database for managing accounts, menus, and transactional data. Utilized Redis for fast caching of frequently accessed data and session management.
*   **Real-time Synchronization**: Built a low-latency, event-driven communication layer using Socket.IO. Implemented room-based event broadcasting to ensure that when a customer places an order, the Kitchen and Waiter dashboards update instantly without page reloads.
*   **AI-Native Engineering**: Actively integrated AI coding agents into the daily workflow for scaffolding boilerplate code, generating automated tests, and debugging complex real-time edge cases, while maintaining strict accountability for code correctness and security.
*   **CI/CD & Cloud Infrastructure**: Configured automated GitHub Actions pipelines for linting, testing, and Snyk security scanning. Engineered a full CD workflow deploying the Frontend to AWS S3/CloudFront and the Dockerized Backend to AWS EC2, fetching secrets securely from AWS SSM Parameter Store.
